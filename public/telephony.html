IIM Setup

AMI and ARI are separate. While a link is enabled it keeps auto-reconnecting after that link's retry delay. Disable it to drop the socket and stop retries. Independent of call-setup drain. Give this process its own ID, name, and description when you run more than one IIM.

This IIM instance

Identity of this process. Other IIM hosts (lab, production, a second bank) must use a different ID. Stored in this instance’s SQLite — keep a separate database file per process.

2–64 letters, numbers, dots, hyphens, or underscores. Assigned on first start if empty.

AMI (Asterisk Manager Interface)

TCP control channel. Defaults: host 127.0.0.1, port 5038, user iim.

ARI (Asterisk REST Interface)

HTTP + WebSocket. Defaults: http://host:8088/ari, user iim, app iim-ivr.

IIM stations (system range)

Agent-side PBX extensions this process owns (default 3001–3999). Other phones (2098, …) are not ours — IIM will not control them. Live view: IIM Station monitor. This is not the inbound DID list; those belong in Inbound routing (for example lab DID 7777).

Voice files (system)

On Asterisk, not on this IIM host. Default /var/lib/asterisk/sounds/custom. Put prompts in language folders: urdu, english, sindhi, pashto, arabic, other5–other9. Menus store the file name only (e.g. BOK_GREETINGS); IIM plays custom/urdu/BOK_GREETINGS (or the current caller language).

Languages (IIM vs Pulse)

IVR uses proc_setlanguage ur (or en, sn, …) for our files and {language} tokens. Pulse Add Call Interaction gets languageQueueId from this table. Old Pulse middleware sent 1 = Urdu, 2 = English.

Code IIM id Name Pulse languageQueueId

IVR menu defaults (system)

Used when a menu leaves a field blank. Wait time starts after the prompt finishes. If the prompt is “none”, nothing is played and the call follows “after too many silences”.

PULSE Swagger (system)

One URL for the whole IIM process — the sidebar PULSE Swagger shortcut. Not an env variable. Example: http://192.168.1.10:8080/swagger. Dummy until you set the real PULSE docs path: https://petstore.swagger.io/

Saving writes SQLite. Env AMI_PASSWORD / ARI_PASSWORD still override at runtime if set. After save, reconnect only the link that is currently enabled.
