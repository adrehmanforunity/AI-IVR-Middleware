Inbound routing

When a call comes in, match DID/trunk and start that IVR at its first menu block (still ringing). Put Pulse Create Interaction, Create Session, then Answer in that document — same pattern as the sample. Fail on a block uses that block’s Then if failed. Post-call survey (CSAT) is optional after the agent hangs up, on the same Pulse session.
